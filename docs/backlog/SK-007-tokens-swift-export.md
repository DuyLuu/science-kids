# SK-007 · Script xuất `tokens.json` → `Tokens.swift`

Trạng thái: review · Ngày: 2026-10-28 · Phụ trách: dev · Tester: tester
Nguồn: docs/ios-test-build.md mốc 1 việc I3; technical-plan.md B3 ("tokens xuất bằng một script nhỏ chạy tay khi đổi"), B7.5, B14 (CI kiểm code sinh ra đã cập nhật); SK-006 (định dạng tokens)

## Mục tiêu
Dev viết một script chạy bằng một lệnh, biến `packages/design-tokens/tokens.json` thành `Tokens.swift` trong module `DesignSystem`, để ios-dev dùng token có kiểu trong SwiftUI và không bao giờ viết hex trong view.

## Phạm vi
- `packages/design-tokens/scripts/export-swift.mjs` (Node, không phụ thuộc ngoài), kèm `package.json` có `npm run export:swift` và `npm run check:swift`.
- Đầu ra: `apps/ios/Packages/SKKit/Sources/DesignSystem/Generated/Tokens.swift`.
  - Dòng đầu: `// Generated by packages/design-tokens/scripts/export-swift.mjs — do not edit`.
  - Chỉ dùng SwiftUI/Foundation; tương thích Swift 6 strict concurrency (mọi hằng là `static let` của kiểu `Sendable`).
- Ánh xạ tối thiểu:
  - `color.*` → `Color` sRGB, tên theo key (`Tokens.Palette.doSon`, `Tokens.Role.actionPrimary`); tham chiếu `{…}` giải ra giá trị;
  - `font.family`, `typography.*` → struct gồm tên font, cỡ, line-height, weight;
  - `radius`, `touch_target`, `space` → `CGFloat`, nhóm theo tuổi bằng `enum AgeGroup { explorer, discoverer, scientist }`;
  - `shadow.*` → mảng lớp `{x, y, blur, spread, color, inset}`;
  - `motion.preset.*` → struct có `duration` (giây), 4 điểm điều khiển bezier, `keyframes`, `repeats`, `delay`;
  - `motion.stagger`, `layout.*` → hằng số cho `LayoutMetrics` (SK-008).
- Tên Swift chuyển `snake_case` → `lowerCamelCase`. Tên trùng từ khoá Swift thì thêm dấu backtick.
- Chạy hai lần cho ra file giống hệt (xếp key ổn định, không ghi giờ sinh).
- `check:swift`: sinh ra bộ nhớ rồi so với file đang có, lệch thì exit 1 và in tên token lệch. CI dùng sau này.
- README của `packages/design-tokens` thêm mục "Xuất Swift".

## Ngoài phạm vi

**Quyết định ánh xạ** (chi tiết ở README mục "Xuất Swift")
1. Không gian tên: `enum Tokens`; mỗi nhóm là `enum` lồng (`Tokens.Motion.Preset.lay`, `Tokens.Layout.Grid.Quiz.compact`). Bỏ một tầng ở `color` và `font` để không có `Tokens.Color`, `Tokens.Font` che `SwiftUI.Color`, `SwiftUI.Font` bên trong `Tokens`: `Tokens.Palette`, `Tokens.Role`, `Tokens.AgeGroupColor`, `Tokens.FontFamily`, `Tokens.FontWeight`.
2. `typography` và `shadow` vừa là nhóm vừa là kiểu: `Tokens.Typography.button` có kiểu `Tokens.Typography`, `Tokens.Shadow.paper3` có kiểu `Tokens.Shadow`. SK-008 viết được `.paperShadow(.paper3)`, `.typography(.button)`.
3. **Tham chiếu ra hằng Swift, không chép giá trị:** `Tokens.Role.actionPrimary: Color = Tokens.Palette.doSon`; bóng là `Tokens.Palette.mucBong.opacity(0.22)`. Giá trị cuối vẫn là màu thật (test so hex). Lý do: đổi một màu gốc thì chỉ một hằng đổi, `check:swift` báo đúng một tên. Đây là cách tôi hiểu "tham chiếu giải ra giá trị"; nếu PM muốn chép hex vào từng vai thì đổi một dòng trong script.
4. `shadow`: `alpha` gộp vào `color` (`.opacity(alpha)`, bỏ khi alpha = 1), nên mỗi lớp đúng `{x, y, blur, spread, color, inset}` như ticket. `blur` giữ nguyên bán kính CSS; hệ số `blur / 2` cho SwiftUI để SK-008 chốt.
5. Đơn vị: `dimension` → `CGFloat` pt; `duration`, `delay` → `TimeInterval` **giây** (60 ms → `0.06`); độ (`rotate`, `rotate_y`, `shape.tilt_*`) → `Angle`; `easing` → `Tokens.CubicBezier(x1, y1, x2, y2)`; `origin` → `UnitPoint`; `text_case` → `Text.Case?` (`none` = `nil`); `typography.dynamic_type.*_category` → `DynamicTypeSize`; `font.weight` → `Int` (Phudu đặt trên trục wght). `iteration` → `repeats: Bool` (chỉ cho phép `1` hoặc `"infinite"`).
6. `illustration.*` (filter SVG, app không chạy) → `String` chứa JSON của giá trị, để vẫn đủ 1 lá = 1 hằng mà không dựng kiểu không ai dùng.
7. "Nhóm theo tuổi": `Tokens.AgeGroup { explorer, discoverer, scientist }` có `.radius`, `.touchTarget`, `.color`. `space.*` không có khoá theo tuổi nên không có tra theo tuổi.
8. Thứ tự theo `tokens.json` (không sắp chữ cái), để giữ cách designer nhóm. Ổn định vì chỉ phụ thuộc file nguồn, không ghi giờ. Không đổi gì thì script không ghi lại file.
9. Mỗi hằng có dòng doc đầu ``/// `đường.dẫn.token` `` (kèm hex hoặc `→ token đích`), dòng sau là `$description`. `check:swift` dò khối của từng token trong file đang có để in tên lệch.
